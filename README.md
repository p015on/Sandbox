# Ostatni Liść

Prototyp gry na telefon: strącaj liście z drzewa i zostaw dokładnie jeden.

Zagraj: https://p015on.github.io/sandbox/

- Stuknięcie zrywa liść i osłabia sąsiadów, przytrzymanie pokazuje skutek ruchu.
- Złap gałąź i odciągnij jak procę: długość naciągnięcia to siła 1–3, a każdy liść wiszący na tej gałęzi traci tyle punktów chwytu. Obrysowane liście to dokładnie te, które spadną.
